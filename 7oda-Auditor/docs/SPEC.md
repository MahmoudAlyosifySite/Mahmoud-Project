# 7oda Auditor — Technical Specification (v0 MVP)

This document is the single source of truth for the MVP. Two independent implementations follow it:

- **Swift** (`AuditorCore/`, runs on the iPhone), and
- **Python** (`research/auditor_ref/`, the reference used for evaluation, fixtures and research).

They must agree numerically. Parity is enforced by fixture files that the Python reference writes and the Swift tests read (section 11). When this spec and an implementation disagree, the implementation is wrong; when the spec is ambiguous, fix the spec first.

Units: seconds, g (accelerometer), rad/s (gyroscope). Sampling rate `fs = 100` Hz. Arrays are 0-indexed. `ln` is the natural log. All arithmetic is IEEE-754 double.

## 2. Random numbers

### 2.1 SplitMix64 (seeding)
State `s: UInt64`. `next()`:
```
s = s &+ 0x9E3779B97F4A7C15
z = s
z = (z ^ (z >> 30)) &* 0xBF58476D1CE4E5B9
z = (z ^ (z >> 27)) &* 0x94D049BB133111EB
return z ^ (z >> 31)
```

### 2.2 xoshiro256** (generation)
Seeded from a `UInt64` seed: `sm = SplitMix64(seed)`; `s0..s3 = sm.next()` four times in order.
`next()`:
```
result = rotl(s1 &* 5, 7) &* 9
t = s1 << 17
s2 ^= s0; s3 ^= s1; s1 ^= s2; s0 ^= s3
s2 ^= t
s3 = rotl(s3, 45)
return result
```
`rotl(x, k) = (x << k) | (x >> (64 - k))`.

- `uniform()` = `Double(next() >> 11) * 0x1.0p-53` (in [0, 1)).
- `uniform(a, b)` = `a + (b - a) * uniform()`.
- `int(lo, hi)` (inclusive) = `lo + min(Int(floor(uniform() * Double(hi - lo + 1))), hi - lo)`.

Python: emulate with `& 0xFFFFFFFFFFFFFFFF` after every multiply/add/shift-left.

On the phone, the seed comes from `SecRandomCopyBytes` (8 bytes, little-endian into `UInt64`). Seeds are serialized as lowercase hex strings with `0x` prefix and exactly 16 digits, e.g. `"0x00000000000004d2"`.

## 3. Challenge (random haptic pattern)

### 3.1 Config (defaults)
| Name | Default |
|---|---|
| leadSilence | U(0.05, 0.10) s |
| tapCount | int(6, 8) |
| tapIntensity | U(0.4, 1.0) |
| tapSharpness | U(0.0, 1.0) |
| tapGap (onset to next onset) | U(0.08, 0.15) s |
| rampCount | 2 (fixed) |
| rampDuration | U(0.15, 0.25) s |
| rampSharpness | U(0.2, 0.8) |
| rampLow / rampMid / rampHigh | U(0.25, 0.5) / U(0.25, 1.0) / U(0.75, 1.0) |
| rampGap (end of ramp to next onset) | U(0.08, 0.12) s |

### 3.2 Algorithm (draw order is normative)
```
rng = Xoshiro256(seed)
lead  = rng.uniform(0.05, 0.10)
n     = rng.int(6, 8)
s1    = 1 + min(Int(floor(rng.uniform() * n)), n - 1)          // slot in 1...n
s2    = 1 + min(Int(floor(rng.uniform() * (n - 1))), n - 2)    // in 1...n-1
if s2 >= s1 { s2 += 1 }
slots = sorted([s1, s2])                                        // ramp 0 gets slots[0]
taps  = for i in 0..<n: (intensity = rng.uniform(0.4, 1.0),
                         sharpness = rng.uniform(0.0, 1.0),
                         gap       = rng.uniform(0.08, 0.15))
ramps = for j in 0..<2: (duration  = rng.uniform(0.15, 0.25),
                         sharpness = rng.uniform(0.2, 0.8),
                         ascending = rng.uniform() < 0.5,
                         low       = rng.uniform(0.25, 0.5),
                         mid       = rng.uniform(0.25, 1.0),
                         high      = rng.uniform(0.75, 1.0),
                         gap       = rng.uniform(0.08, 0.12))
t = lead; events = []
for i in 0..<n:
    events.append(tap(time: t, intensity, sharpness)); t += taps[i].gap
    for j in 0..<2 where slots[j] == i + 1:
        d = ramps[j].duration
        curve = ascending ? [(0, low), (d/2, mid), (d, high)] : [(0, high), (d/2, mid), (d, low)]
        events.append(ramp(time: t, duration: d, sharpness, curve)); t += d + ramps[j].gap
duration = t
```
Because `s1 != s2`, the two ramps are always separated by at least one tap, and the first event is always a tap. The median pattern is about 1.45 s (range ~1.0–1.9 s).

### 3.3 Intensity curve
`curve(τ)` for a ramp, `τ` in seconds from ramp start: piecewise-linear interpolation of the control points, clamped to the first/last value outside `[0, d]`.

### 3.4 JSON (`ChallengeSpec`)
```json
{"version": 1, "seed": "0x00000000000004d2", "duration": 1.4312,
 "events": [
   {"kind": "tap",  "time": 0.071, "intensity": 0.83, "sharpness": 0.41},
   {"kind": "ramp", "time": 0.52,  "duration": 0.19, "sharpness": 0.47,
    "curve": [{"time": 0.0, "intensity": 0.31}, {"time": 0.095, "intensity": 0.66}, {"time": 0.19, "intensity": 0.93}]}
 ]}
```
Tap objects have no `duration`/`curve`; ramp objects have no `intensity`. Unknown keys are ignored when decoding.

### 3.5 Core Haptics mapping (app only)
- Tap → `CHHapticEvent(eventType: .hapticTransient, parameters: [intensity, sharpness], relativeTime: time)`.
- Ramp → `CHHapticEvent(eventType: .hapticContinuous, parameters: [intensity = 1.0, sharpness], relativeTime: time, duration: d)` plus one `CHHapticParameterCurve(parameterID: .hapticIntensityControl, controlPoints: [(0, c0), (d/2, c1), (d, c2), (d + 0.01, 1.0)], relativeTime: time)`. The last point resets the control to 1.0 after the ramp so later taps keep their own intensity.
- Played with an advanced pattern player, `engine.playsHapticsOnly = true`, `engine.isAutoShutdownEnabled = false`.

## 4. Recording (raw data, also the export format)

```json
{
  "schema": "7oda-auditor.recording.v1",
  "id": "8E0B…",                       // UUID string
  "createdAt": "2026-11-24T10:00:00Z",  // ISO-8601, UTC
  "purpose": "check",                   // calibration | enrollment | accessory | check | test | signalCheck
  "label": {"personID": "…", "personName": "…", "hand": "right", "accessory": "none",
            "posture": "sitting", "sessionID": "…"},          // or null
  "challenge": { …ChallengeSpec… },
  "hapticStart": 81234.5612,            // seconds, same clock as the sensor timestamps (systemUptime)
  "accel":  {"t": […], "x": […], "y": […], "z": […]},          // CMAccelerometerData, g, includes gravity
  "gyro":   {"t": […], "x": […], "y": […], "z": […]},          // CMGyroData, rad/s, raw
  "motion": {"t": […],
             "gravityX": […], "gravityY": […], "gravityZ": […],
             "userAccelX": […], "userAccelY": […], "userAccelZ": […],
             "rotationX": […], "rotationY": […], "rotationZ": […],
             "attitudeW": […], "attitudeX": […], "attitudeY": […], "attitudeZ": […]},
  "device": {"model": "iPhone16,1", "system": "iOS 26.1", "app": "0.1.0 (1)"}
}
```
- `hand`: `right | left`. `accessory`: `none | watch | ring | bracelet | other`. `posture`: `sitting | standing | freshGrip | unspecified`.
- Dates are ISO-8601 in UTC **without fractional seconds** (`2026-11-24T10:00:00Z`), which is what `JSONEncoder.DateEncodingStrategy.iso8601` reads and writes.
- Optional keys may be absent: `label`, `device`. Arrays within a stream have equal length. Timestamps may be unsorted or duplicated; processing sorts them (stable) and drops any sample whose `t` is not strictly greater than the previous kept sample.
- Export files are JSON Lines: one recording per line (`recordings.jsonl`).

## 5. Signal processing

### 5.1 Config (defaults)
| Name | Default |
|---|---|
| fs | 100.0 |
| preRoll / postRoll | 0.25 s / 0.25 s |
| hpCutoff | 5.0 Hz, Q = 1/√2 |
| motionLowPass | 3.0 Hz, Q = 1/√2 |
| tremor band-pass | f0 = √(8·12) = 9.797958971132712 Hz, Q = f0 / 4 |
| pad | 30 samples |
| gapTolerance | 0.025 s |
| lag range | −10 … +25 samples |
| templateDecay | 0.03 s |
| accelNoiseFloor / gyroNoiseFloor | 1e-6 / 1e-6 |

### 5.2 Grid and resampling
```
t0 = hapticStart - preRoll
N  = Int((preRoll + duration + postRoll) * fs + 0.5)        // round half up; duration from the challenge
grid[k] = t0 + Double(k) / fs, k = 0..<N
```
For each stream (after sort/dedup, timestamps `ts`, values `v`), for each grid time `g`:
- `j` = largest index with `ts[j] <= g` (binary search), or −1 if none.
- If `j == -1`: value = `v[0]`, missing = true.
- If `j == last`: value = `v[last]`, missing = `(g - ts[last]) > gapTolerance`.
- Else: `w = (g - ts[j]) / (ts[j+1] - ts[j])`, value = `v[j] + w * (v[j+1] - v[j])`, missing = `(ts[j+1] - ts[j]) > gapTolerance`.
- A stream with zero samples gives all zeros and all missing.

`gapFraction` = fraction of grid points missing in **either** the accel or the gyro stream (motion stream excluded).
`sampleRate` = `1 / median(diff(ts_accel))` over the sorted, deduplicated accel timestamps (0 if fewer than 2).

Grid channels: `ax, ay, az` (accel), `gx, gy, gz` (gyro), `Gx, Gy, Gz` (motion gravity), `rx, ry, rz` (motion rotation).

### 5.3 Biquads (RBJ cookbook)
```
w0 = 2π fc / fs, c = cos(w0), s = sin(w0), α = s / (2Q)
high-pass: b = [(1+c)/2, -(1+c), (1+c)/2]
low-pass:  b = [(1-c)/2,  (1-c), (1-c)/2]
band-pass (0 dB peak): b = [α, 0, -α]
a = [1+α, -2c, 1-α];  divide all b and a by a[0]  (so a0 = 1)
```
Direct form I with zero initial state: `y[n] = b0 x[n] + b1 x[n-1] + b2 x[n-2] - a1 y[n-1] - a2 y[n-2]`, out-of-range terms = 0.

### 5.4 Zero-phase filter `filtfiltZ(x, b, a, pad, dcGain)`
`dcGain` = 1 for low-pass, 0 for high-pass and band-pass. With `n = len(x)`:
```
if n == 0: return []
if n == 1: return [dcGain * x[0]]
P   = min(pad, n - 1)
pre = [2*x[0]   - x[k] for k in P, P-1, …, 1]
post= [2*x[n-1] - x[k] for k in n-2, n-3, …, n-1-P]
xp  = pre + x + post                                  // length n + 2P
c1  = xp[0];  y = lfilter(b, a, xp - c1) + dcGain*c1
r   = reverse(y); c2 = r[0];  z = lfilter(b, a, r - c2) + dcGain*c2
return reverse(z)[P ..< P+n]
```

### 5.5 Derived signals (all on the grid, length N)
- `aH[c] = filtfiltZ(a_c, HP)`, `gH[c] = filtfiltZ(g_c, HP)` for c ∈ {x, y, z}.
- `EA[n] = aH_x² + aH_y² + aH_z²`, `EG[n] = gH_x² + gH_y² + gH_z²`.
- `preEnd = Int(preRoll * fs + 0.5) - 5` (= 20). `nA = max(mean(EA[0..<preEnd]), accelNoiseFloor)`, `nG = max(mean(EG[0..<preEnd]), gyroNoiseFloor)`. If `preEnd < 1`, use the floors.
- Normalized energy `env[n] = EA[n]/nA + EG[n]/nG`; amplitude envelope `x[n] = sqrt(env[n])`.

### 5.6 Template and alignment
Template amplitude at lag 0, `τ = Double(n)/fs - preRoll` (time relative to pattern start):
```
h[n] = Σ_taps  (τ >= t_i ? I_i * exp(-(τ - t_i)/templateDecay) : 0)
     + Σ_ramps (t <= τ < t+d ? curve(τ - t)
               : τ >= t+d ? curve(d) * exp(-(τ - t - d)/templateDecay) : 0)
```
For each lag `L` in `lagMin…lagMax`: overlap `n ∈ [max(0, L), min(N, N + L))`, pair `x[n]` with `h[n - L]`; Pearson correlation over the overlap (0 if overlap < 10 or either variance is 0).
- `lag` = argmax (ties → smaller |L|, then smaller L). `ncc` = the max.
- `peakMargin` = `ncc - max{ncc(L') : |L' - lag| >= 4}` (if no such L', `peakMargin = ncc`).

### 5.7 Event indices (after alignment)
For an event at pattern time `t`: `idx(t) = Int((preRoll + t) * fs + 0.5) + lag`. Ramp end: `idx(t + d)`. Pattern end: `endIdx = idx(duration)`. Indices are clamped to `[0, N]` where used as range bounds.
- `onsetFirst = idx(events[0].time)`.
- Quiet window `Q = [0, onsetFirst - 2)`. If its length < 10, use `Q = [min(endIdx + 5, N - 10), N)` (floor at 0).

## 6. Quality gate

### 6.1 Metrics
| Metric | Definition |
|---|---|
| gapFraction | 5.2 |
| sampleRate | 5.2 |
| quietGyroRMS | `sqrt(mean_{n∈Q} EG[n])` |
| quietAccelRMS | `sqrt(mean_{n∈Q} EA[n])` |
| gravityZ | `|mean_n Gz[n]|` over the whole grid (motion gravity) |
| motionRMS | `sqrt(mean_n (rLx² + rLy² + rLz²))` where `rL_c = filtfiltZ(r_c, LP 3 Hz)` |
| gravityAngleDeg | angle in degrees between mean(G) over the first 20 samples and mean(G) over the last 20 samples (0 if either norm < 1e-9; `acos` argument clamped to [−1, 1]) |
| ncc, peakMargin, lag | 5.6 |
| snr | `mean_{n∈Ev} env[n] / max(mean_{n∈Q} env[n], 1e-9)` where `Ev = [onsetFirst, endIdx)` |

### 6.2 Thresholds (defaults)
| Name | Default |
|---|---|
| maxGapFraction | 0.10 |
| minSampleRate | 70 Hz |
| restingGyroFactor | 2.5 (× calibration `quietGyroRMS`) |
| restingGyroAbsolute | 0.004 rad/s (used when no calibration) |
| flatGravityZ | 0.95 |
| maxMotionRMS | 0.30 rad/s |
| maxGravityAngleDeg | 10 |
| minNCC | 0.30 |
| minSNR | 2.0 |

### 6.3 Rules
Mode `handheld` (enrollment, checks) issues, evaluated in this order and all reported:
1. `sensorGaps` if `gapFraction > maxGapFraction`.
2. `lowSampleRate` if `sampleRate < minSampleRate`.
3. `resting` ("Hold the phone") if `gravityZ >= flatGravityZ` and `quietGyroRMS < restThreshold`, where `restThreshold = restingGyroFactor * calibration.quietGyroRMS` if a calibration exists else `restingGyroAbsolute`.
4. `moving` ("Hold still") if `motionRMS > maxMotionRMS` or `gravityAngleDeg > maxGravityAngleDeg`.
5. `weakAlignment` if `ncc < minNCC`.
6. `weakSignal` if `snr < minSNR`.

Mode `onTable` (calibration): rules 1, 2, 5, 6, plus `notResting` if `gravityZ < flatGravityZ` or `motionRMS > 0.05`.

`passed = issues.isEmpty`. User messages: resting → "Hold the phone in one hand", moving → "Hold still", notResting → "Put the phone flat on a table and don't touch it", sensorGaps/weakAlignment → "Try again", weakSignal → "Vibration too weak — remove a thick case?", lowSampleRate → "Motion sensors are too slow on this device".

## 7. Features (v0, `featureVersion = 1`, d = 36)

Inputs: processed signal (section 5), challenge, lag, calibration (optional). Let `taps` be the tap events in time order and `ramps` the ramp events in time order.

### 7.1 Tap windows
For tap i with onset `o_i = idx(t_i)` and next-event onset `next_i` (the onset of the next event of any kind, or `endIdx + 25` for the last event):
`W_i = [max(o_i - 1, 0), min(o_i + 9, next_i - 1, N))`. If the window is empty, the tap is skipped (if all taps are skipped, the tap features are all 0).
- `E_{i,c} = Σ_{n∈W_i} aH_c[n]²` for c ∈ {x,y,z} (accel), and with `gH` for the gyro → 6 energies, channel order `ax, ay, az, gx, gy, gz`.
- `EA_i = Σ accel energies`, `EG_i = Σ gyro energies`.
- Peak `p_i` = argmax of `env[n]` over `n ∈ [W_i.start, min(o_i + 3, W_i.end))` (first max on ties; if that range is empty use `W_i.start`).
- Decay: points `n = p_i … min(p_i + 4, W_i.end - 1)`; if at least 3 points, `decay_i = -slope` of least squares of `ln(env[n] + 0.1)` vs `(n - p_i)`; else `decay_i = 0`.
- Settle: `settle_i` = smallest `k ≥ 0` with `p_i + k < W_i.end` and `env[p_i + k] < 0.1 * env[p_i]`; if none, `settle_i = W_i.end - p_i`.

### 7.2 Ridge regression helper
`ridge3(rows x_i = [1, u_i, v_i], targets y_i, λ)` minimizes `Σ (y_i − x_iᵀθ)² + λ(θ₁² + θ₂²)` (intercept not penalized): solve the 3×3 system `(XᵀX + diag(0, λ, λ)) θ = Xᵀy` by Gaussian elimination with partial pivoting. With `u_i = ln(I_i)`, `v_i = S_i − 0.5`, `λ = 0.01`.
`ridge2(rows [1, u_i], y_i, λ)` is the same with one slope (`λ` on the slope only).

### 7.3 Tap features (indices 0–16)
| # | Name | Definition |
|---|---|---|
| 0–5 | tap_alpha_{ax,ay,az,gx,gy,gz} | intercept θ₀ of `ridge3` with `y_i = ln(E_{i,c} + 1e-7)` |
| 6 | tap_beta_total | θ₁ of `ridge3` with `y_i = ln(EA_i/1e-4 + EG_i/1e-4 + 1e-6)` |
| 7 | tap_gamma_total | θ₂ of the same fit |
| 8–10 | tap_share_{ax,ay,az} | `median_i(E_{i,c} / (EA_i + 1e-12))` |
| 11–13 | tap_share_{gx,gy,gz} | `median_i(E_{i,c} / (EG_i + 1e-12))` |
| 14 | tap_log_accel_gyro_ratio | `median_i ln((EA_i + 1e-7) / (EG_i + 1e-7))` |
| 15 | tap_decay | `median_i decay_i` |
| 16 | tap_settle | `mean_i settle_i` |

Median: numpy semantics (mean of the two middle values for even counts).

### 7.4 Ramp features (indices 17–28)
For ramp j: `s = idx(t_j)`, `e = idx(t_j + d_j)` (clamped to `[0, N]`).
`ampA[n] = sqrt(EA[n])`, `ampG[n] = sqrt(EG[n])`. Commanded intensity at sample n: `I(n) = curve(τ)` with `τ = clamp(Double(n - lag)/fs - preRoll - t_j, 0, d_j)`.
- Gain fit on `n ∈ [s + 2, e)`: `ridge2` with `u = ln(I(n))`, `y = ln(ampA[n] + 1e-4)`, `λ = 0.001` → `ρA_j = θ₀`, `κA_j = θ₁`; same with `ampG` → `ρG_j`, `κG_j`. If fewer than 3 points: `κ = 1`, `ρ = mean(y) − mean(u)` (0 if no points).
- `rise_j` = smallest `k ≥ 0` with `s + k < e` and `ampA[s + k] >= 0.63 * max(ampA[s..<e])`; if `s >= e`, 0.
- `decayT_j`: `ref = mean(ampA[e-2], ampA[e-1])` (only indices inside `[s, e)`; if none, ref = 0); smallest `k` in `0..<10` with `e + k < N` and `ampA[e + k] < 0.37 * ref`; if none, 10.
- Shares: `Σ_{n∈[s,e)} aH_c[n]² / (Σ_{n∈[s,e)} EA[n] + 1e-12)` for c ∈ {x,y,z}; gyro likewise with `gH` and `EG`.

| # | Name | Definition (mean over ramps) |
|---|---|---|
| 17 | ramp_gain_accel | ρA |
| 18 | ramp_exponent_accel | κA |
| 19 | ramp_gain_gyro | ρG |
| 20 | ramp_exponent_gyro | κG |
| 21 | ramp_rise | rise |
| 22 | ramp_decay | decayT |
| 23–25 | ramp_share_{ax,ay,az} | accel shares |
| 26–28 | ramp_share_{gx,gy,gz} | gyro shares |

### 7.5 Quiet and grip features (indices 29–35)
`bA[c] = filtfiltZ(a_c, BP tremor)` and `bG[c]` likewise on the whole grid.
| # | Name | Definition |
|---|---|---|
| 29 | quiet_tremor_accel | `ln(mean_{n∈Q} Σ_c bA_c[n]² + 1e-10)` |
| 30 | quiet_tremor_gyro | `ln(mean_{n∈Q} Σ_c bG_c[n]² + 1e-10)` |
| 31 | quiet_rms_accel | `ln(sqrt(mean_{n∈Q} EA[n]) + 1e-6)` |
| 32 | quiet_rms_gyro | `ln(sqrt(mean_{n∈Q} EG[n]) + 1e-6)` |
| 33–35 | gravity_{x,y,z} | mean of (Gx, Gy, Gz) over the grid, normalized to unit length; `[0, 0, -1]` if the norm < 1e-6 |

### 7.6 Calibration-relative features
Indices `R = {0,1,2,3,4,5,6,7,14,17,18,19,20}` are reported relative to the phone on the table: `f[r] − calibration.tableFeatures[r]`. Without a calibration they are absolute. (Within one phone this is a constant offset and does not change identification; it matters across phones.)

## 8. Calibration
- 20 patterns with the phone flat on a table, quality mode `onTable`. At least 12 must pass, else calibration fails ("Calibration failed: keep the phone still on a hard table").
- `tableFeatures[k]` = median over passing patterns of the **absolute** feature k (all 36 stored; only R is used).
- `quietGyroRMS`, `quietAccelRMS` = median over passing patterns.
- Also stored: median `sampleRate`, median `ncc`, median `snr`, count used, date, device model.

JSON: `{"version":1,"createdAt":…,"tableFeatures":[36],"quietGyroRMS":…,"quietAccelRMS":…,"sampleRate":…,"ncc":…,"snr":…,"patternsUsed":…,"device":"…"}`.

## 9. Recognition model (v0)

### 9.1 Prototypes
A prototype is one `(personID, hand, accessory)` combination. Every stored template sample belongs to one prototype. Classes of the Gaussian model = prototypes, in a deterministic order: sort by `(personID string, hand: right < left, accessory order none < watch < ring < bracelet < other)`.

### 9.2 Training (`GaussianModel.fit`)
Input `X` (n × d), prototype indices `k_i`. Config: `shrinkageMin = 0.1`, `looQuantile = 0.95`, `absFactor = 1.5`.
1. `μ_j = mean_i X_ij`, `σ_j = sqrt(mean_i (X_ij − μ_j)²)`, then `σ_j = max(σ_j, 1e-6)`. `z_i = (x_i − μ) / σ`.
2. `m_k` = mean of `z_i` over class k; `n_k` = count.
3. Residuals `r_i = z_i − m_{k_i}` (matrix R, n × d).
4. Ledoit–Wolf shrinkage of R (assume centered), exactly as follows:
   ```
   S_emp = RᵀR / n
   trace_j = Σ_i R_ij² / n ;  mu = Σ_j trace_j / d
   beta_   = Σ_{j,k} (Σ_i R_ij² R_ik²)
   delta_  = Σ_{j,k} (RᵀR)_{jk}² / n²
   beta    = (beta_/n − delta_) / (d·n)
   delta   = (delta_ − 2·mu·Σ_j trace_j + d·mu²) / d
   beta    = min(beta, delta)
   λ_LW    = (delta == 0) ? 0 : beta / delta
   λ       = clamp(max(λ_LW, shrinkageMin), 0, 1)
   S       = (1 − λ)·S_emp + λ·mu·I
   ```
   Degenerate case: if `n − K < 2` or `mu <= 1e-12`, use `S = I` and `λ = 1`.
5. Cholesky `S = L Lᵀ` (lower triangular). If it fails (non-positive pivot), add `1e-6·mu·I` and retry up to 5 times, multiplying the jitter by 10 each time.
6. Distance to class k: `D²_k(x) = ‖L⁻¹(z − m_k)‖²` with `z = (x − μ)/σ` (forward substitution).
7. Leave-one-out threshold: for every sample i with `n_{k_i} ≥ 2`: `m' = (n_k m_k − z_i)/(n_k − 1)`, `loo_i = ‖L⁻¹(z_i − m')‖²`. `absThreshold = absFactor × quantile(loo, looQuantile)` (numpy "linear" quantile). If no sample qualifies: `absThreshold = absFactor × 2 × d`.

### 9.3 Hand head
A second `GaussianModel` with two classes, `right` (class 0) and `left` (class 1), trained on all samples (all persons, all accessories) with the same config. It exists only if both hands have at least 2 samples. Log-odds for "right": `h(x) = (D²_left(x) − D²_right(x)) / 2`.

### 9.4 Decision (sequential, per check)
Config: `nameMargin = 6.0`, `handMargin = 3.0`, `maxPatterns = 3`.
After pattern m (feature vectors x⁽¹⁾…x⁽ᵐ⁾ that passed quality):
```
D̄_k = mean_j D²_k(x⁽ʲ⁾)            h̄ = mean_j h(x⁽ʲ⁾)  (0 if no hand head)
k*  = argmin_k D̄_k  (ties → lowest index);  p* = person(k*), hand* = hand(k*)
otherPerson = min{D̄_k : person(k) ≠ p*}          (+∞ if none)
otherHand   = min{D̄_k : person(k) = p*, hand(k) ≠ hand*}   (+∞ if none)
marginName = otherPerson − D̄_{k*};  marginHand = otherHand − D̄_{k*}
absOK   = D̄_{k*} <= absThreshold
nameOK  = marginName >= nameMargin
headOK  = no hand head  OR (hand* == right ? h̄ > 0 : h̄ < 0)
handOK  = marginHand >= handMargin AND headOK
if absOK && nameOK && handOK      → identified(p*, hand*)            [stop]
else if m < maxPatterns           → needMorePatterns                [play another]
else if absOK && nameOK           → identifiedHandUnclear(p*)
else                              → unknown(reason)   reason ∈ {noMatch (absOK false), ambiguous (nameOK false)}
```
With no prototypes at all the decision is `unknown(noPeople)`. Persons scores for display: `score_p = softmax_p(−min_{k∈p} D̄_k / 2)`.

### 9.5 Template updates
After `identified(p, h)` with `marginName ≥ 2 × nameMargin` and `D̄_{k*} ≤ 0.75 × absThreshold` (and the user setting "Learn from confident checks" on), each pattern's feature vector is added to prototype `k*` as an `adaptive` sample. Keep at most 20 adaptive samples per prototype (drop the oldest). Enrollment and accessory samples are never dropped. Retrain after every change. Unknown, hand-unclear and low-margin results are never learned.

### 9.6 Hand challenge (optional)
When enabled, the app asks for a random hand (`uniform() < 0.5 → right`). The check passes only if the decision is `identified(p, h)` with `h` equal to the requested hand.

## 14. v1 learned encoder (research now, phone later)

v1 replaces the hand-made features with a learned embedding. It ships to the phone only if it beats v0 on cross-session accuracy (proposal; D7). This section is the contract between the training code (`research/v1/`) and the future on-device integration.

### 14.1 Input tensor `x`: float32, shape `[1, 10, 256]`
Built from a `ProcessedSignal` `p` (section 5) with `s = p.alignment.lag`. Time index `u ∈ 0..<256` reads grid index `n = u + s`; if `n ∉ [0, N)` the value is 0 in every channel. The pattern therefore always starts at `u = 25`.
| Channel | Value |
|---|---|
| 0–2 | `accelHP[c][n] / 0.02` |
| 3–5 | `gyroHP[c][n] / 0.05` |
| 6–8 | `gravity[c][n]` (device-motion gravity, g) |
| 9 | `template[u]` (the lag-0 template of 5.6, evaluated at `u`, 0 if `u ≥ N`) |
All values are clipped to `[-50, 50]`.

### 14.2 Outputs
- `embedding`: `[1, 128]`, L2-normalized.
- `hand`: `[1, 3]` logits for `right, left, twoHanded`.

### 14.3 On-device scoring (mirrors 9.4 with similarities)
Prototype = L2-normalized mean embedding of a `(person, hand, accessory)`. Score = cosine similarity. Fused over patterns by averaging. `absThreshold` = `quantile_{1−looQuantile}` of leave-one-out similarities minus a slack (tuned on held-out sessions); name and hand margins are similarity differences. The hand head replaces the pooled Gaussian hand model.

### 14.4 Core ML artifact
`HandEncoder.mlpackage`, ML Program, minimum deployment iOS 17, input name `x`, outputs `embedding` and `hand`, weights 8-bit palettized, target size < 1 MB, latency < 10 ms. Exported by `research/v1/export_coreml.py` together with `reference_io.npz` (inputs and PyTorch outputs) so the conversion can be checked on macOS.
