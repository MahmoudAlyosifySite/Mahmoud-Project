# Mahmoud-Project

This repository holds two separate projects, each in its own folder with its own README.

| Folder | Project | State |
|---|---|---|
| [`conservation-teacher/`](conservation-teacher/) | *Impossible or Merely Improbable?* A research project: a three-way test of physical surprise in latent world models. Code, pre-registered protocol, results ledger and paper draft. | Stages A to C run; paper draft and arXiv bundle in `conservation-teacher/paper/`. |
| [`BA/`](BA/) | **BA — Your Voice. Your Identity.** A personalized multilingual voice generation project. | Vision only; no code yet. |

Each project has its own rules: read the README (and, for `conservation-teacher/`, its `CLAUDE.md`) inside the folder before working there.
