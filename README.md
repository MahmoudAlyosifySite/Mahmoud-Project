# Mahmoud-Project

This repository holds four separate projects, each in its own folder with its own README.

| Folder | Project | State |
|---|---|---|
| [`conservation-teacher/`](conservation-teacher/) | *Impossible or Merely Improbable?* A research project: a three-way test of physical surprise in latent world models. Code, pre-registered protocol, results ledger and paper draft. | Stages A to C run; paper draft and arXiv bundle in `conservation-teacher/paper/`. |
| [`BA/`](BA/) | **BA — Your Voice. Your Identity.** A personalized multilingual voice generation project. | v0.1.0 published on Hugging Face: model `mahmoudalyosify/BA` and demo Space `spaces/mahmoudalyosify/BA`. |
| [`SimCLR-Vision-SSL/`](SimCLR-Vision-SSL/) | *Spend Your Labels Last: Why Supervised Contrastive Pretraining Falls Behind Self-Supervision When Labels Are Scarce.* SimCLR / SupCon study on CIFAR-10 with code, runs, paper and a visual-search deployment. | Snapshot copied 2026-11-15 from its own repository (`MirnaEmbaby/SimCLR-Vision-SSL`), including uncommitted work in progress at that time. |
| [`7oda-Auditor/`](7oda-Auditor/) | **7oda Auditor** — an offline iPhone and Android app that names who is holding the phone, and with which hand, from how the hand absorbs a short random vibration (Core Haptics + Core Motion), with a learned Core ML encoder trained on the A40. | MVP complete for iOS and Android; all builds and tests green in CI; install files on the `7oda-auditor-latest` release; not yet run on a physical phone. |

Each project has its own rules: read the README (and, for `conservation-teacher/`, its `CLAUDE.md`) inside the folder before working there.
